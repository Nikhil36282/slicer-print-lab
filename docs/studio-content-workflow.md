# Studio & content workflow

Keep the full model catalogue in a private Google Sheet and selected work on a private Trello board. This guide is reusable; inventory, account details, media, publication results and live board links belong in private records.

## Catalogue

Preserve existing columns and append: **Model ID**, **Making stage**, **Next action**, **Trello link**, **Media folder link**. Assign permanent values such as N3D-0001; never regenerate IDs after sorting or deleting rows. New models get the next unused ID. Count nonblank model records before reporting inventory totals.

Use stages: Not started, Printing, Support removal, Sanding/filling, Primer, Painting, Assembly, Final photos, Finished, Needs verification. Existing print/colour flags are evidence of those milestones only; they do not establish assembly, quality or filming readiness. Keep unknown links blank until real destinations exist.

## Trello board

Create **Nerds3DStudio — Studio & Content**, visibility **Private**, with lists in this order:

1. Backlog
2. This Week
3. In Progress
4. Waiting
5. Done
6. Templates & Routine

Keep at most three cards In Progress. Give every selected active card one owner, one explicit next action, a card-level due date and an enabled due-date reminder. Waiting cards also need a blocker and review date. A checklist date alone is not the notification mechanism.

Use the [model project template](../templates/model-project-card.md) and [content post template](../templates/content-post-card.md). Put model IDs in both titles and link related cards. Finishing a model and publishing content are separate outcomes. A content card is Done only when its specified destination is published and the post link recorded. Create separate publishing cards for destinations with unavailable accounts so preparation and other publishing can finish independently.

## Weekly content routine: five hours

| Work | Budget | Output |
| --- | --- | --- |
| Film | 90 minutes | Reveals, detail close-ups, process clips |
| Edit | 120 minutes | Two short clean video masters with English text |
| Publish and reply | 60 minutes | Two Instagram Reels; Shorts when account access is ready; one adapted Reddit post when access is ready |
| Sunday review | 30 minutes | Updated milestones, next actions and next week's selection |

Use hands/model footage and music. Save a master without platform-added music. Add permitted audio separately for each destination. Before preparing a Reddit post, select a relevant community and read its current posting rules. Do not auto-publish.

Record each platform's post link and publication date. Set a card-level review date seven days later. Record views, meaningful comments, saves where available and enquiries; use unavailable rather than zero for unsupported metrics. Note one observation and one next experiment. Do not imply an unpublished platform has results.

## Phone routine

Google Calendar events use Asia/Kolkata time:

- Monday–Saturday, 20:00–20:05: **Nerds3DStudio — daily studio check**. Complete work actually finished; inspect overdue cards; move blocked tasks to Waiting with a review date; choose tomorrow's next action. Include private catalogue and board links.
- Sunday, 20:00–20:30: **Nerds3DStudio — weekly studio review**. Reconcile catalogue milestones, review seven-day results, select two videos and one Reddit adaptation, keep In Progress at three or fewer, and check reminders. Include the same links. This replaces Sunday's short check.

Enable event notifications and Android notifications for Calendar. In Trello, assign the user to active cards and explicitly configure each card's due reminder. Enable Android notifications for Trello. Create a near-term test while the user is available, and confirm actual phone delivery before marking notifications ready. These prompts do not detect physical printing or painting progress.

## One-week pilot and validation

Start dates from the actual setup day, not a stale template date. Begin with three example subjects and verify physical availability before filming. Keep account-dependent publication cards in Waiting.

- Compare original sheet values and formulas before/after; only the authorized additions should change.
- Check each model ID, row link, card and media link against the correct model.
- Use clearly labelled TEST cards to exercise Backlog → This Week → In Progress → Waiting → In Progress → Done. Record a mock blocker and review date. Complete a model checklist and a content checklist with test evidence, never real completion claims.
- Give another TEST card a past due date and leave incomplete. Confirm overdue display, then reschedule with a reason and enable its reminder. This tests overdue handling, not past notification delivery.
- Archive test cards after documenting results privately.
- Confirm the board is private, card owners/reminders are set, both recurrences use the correct timezone, and the Android test arrived.
- At the first Sunday review, reduce workload if preparation exceeds six hours or posting is repeatedly missed. Record what changed.

## Setup status

This document specifies the workflow; it does not prove that live services or phone notifications have been configured. Track connection, creation and validation status privately. No automatic catalogue synchronization, sales workflow, order handling or paid tools are required.
