# Adding useful experiments

Create a record from `templates/print-record.md`, link it in `prints/README.md`, and add a selected settings snapshot if useful. Give failures the same care as successes. Distinguish proposed settings, inspected slices, and inspected physical prints.

Update the skill only when a demonstrated result improves a reusable decision. Keep the geometry, material, nozzle, and scale context with any recipe. Add resources with attribution and a note explaining when to use them.

Before a public commit, review added files for local paths, identifiers, credentials, personal photographs, and model sharing rights. The `.gitignore` excludes common model and project formats, but this does not replace reviewing the actual staged files.

Keep commits focused on one useful update. Never force-push a shared history just to tidy an experiment.
