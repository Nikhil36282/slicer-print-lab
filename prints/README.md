## Evidence levels

| Status | Meaning |
|---|---|
| Proposed | Settings chosen; the slice has not yet been inspected |
| Slicer-verified | A slice completed and its preview was inspected; physical quality remains unknown |
| Print-verified | The physical print was inspected and the record documents the outcome |
| Failed / needs revision | A physical failure or unacceptable finish is documented |

Use the [template](../templates/print-record.md) for new entries. A print-verified record can still have limitations; explain which surfaces, fits, or failure modes were checked.
