# Failure evidence and retry record

Record the model/version and scale, physical printer/nozzle/plate, actual filament and condition, slicer version, saved project, and process preset. Missing facts remain unknown.

For each failed area, record:
- Observation: photo or user report, location, layer/height, whether a support or model feature moved, and when the failure began.
- Baseline: support/interface/overhang speeds, acceleration, support geometry and anchoring, adhesion, and relevant object overrides.
- Hypothesis: possible cause and alternatives; user suspicion alone does not confirm excessive speed.
- Trial: smallest representative section when useful, targeted changes, expected result, and parameters kept comparable.
- Outcome: completion, support stability, underside finish, removal damage, time, and fit. Record live speed changes too.
- Conclusion: supported cause, remaining uncertainty, and next experiment. Promote a fix only after a documented physical comparison supports it.

Keep project variants so a failed experiment can be reversed. Use public-safe notes and selected settings; do not publish model files or photos without the applicable authorization and redistribution rights.
