# Working in this repository

Maintain a clear distinction between proposed settings, slicer verification, and physical print verification. Do not claim a recipe worked unless a physical result is documented.

Use the skill in `skills/bambu-a1-print-quality/SKILL.md` for A1 model preparation. Save working model/3MF files locally outside this repository unless redistribution is authorized. This repository is public: do not commit credentials, printer identifiers, private paths, or downloaded model files.

When the user asks to retain a print result, add a dated record, update the journal index, and store relevant selected settings. When asked to publish those changes, review the diff and push a focused commit. A print-preparation request alone does not authorize a GitHub push or a physical print.

Keep resources curated and attributed. If modifying the skill, validate its frontmatter and scope; update the installed local copy only when authorized. Do not overwrite unrelated user changes or force-push.
